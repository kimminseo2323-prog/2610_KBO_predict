# 사이트 구성 개편안 — 소식 / 이번 시즌 / 지난 시즌 / 팀 / 선수 / 모델 성적표 (샘플, 2026-11-09)

> 상태: **1단계 적용 (2026-11-09)** — 메뉴 순서, 첫 화면 = 이번 시즌, 지난 시즌 페이지, 이번 시즌 순위표·다가오는 경기·시즌 종료 카드. 2단계(경기일 다시 보기를 지난 시즌으로 옮기기)와 4(과거 시즌 경기별 예측)는 아직.

## 1. 메뉴와 주소

| 순서 | 메뉴 | 주소 | 하는 일 |
|---|---|---|---|
| 1 | 소식 | `news.html` | 구단별 뉴스 (네이버 검색 API → Cloudflare 프록시). 구단 탭·즐겨찾기 |
| 2 | 이번 시즌 | `index.html` (첫 화면) | 지금 진행 중인 시즌 운영: 오늘 경기 예측, 일정, 순위, 전망, 매일 예측 기록 |
| 3 | 지난 시즌 | `seasons.html?season=YYYY` | 연도별 우승 팀, 한국시리즈 경기별 결과, 가을야구 대진, 최종 순위, 그 시즌 모델 성적, 경기일 다시 보기 |
| 4 | 팀 | `teams.html` | 그대로 |
| 5 | 선수 | `players.html` | 그대로 |
| 6 | 모델 성적표 | `report.html` | 그대로 |

- 첫 화면(사이트 주소로 들어왔을 때)은 **이번 시즌**으로 둔다(제안). 메뉴 순서는 소식이 처음이지만, 소식은 API 연결 전이라 기사 목록이 비어 있고 "오늘 경기 예측"이 이 사이트의 핵심이기 때문. 소식을 첫 화면으로 할지는 결정 필요.
- `index.html` 주소는 그대로 둔다(이미 공유된 링크·`?date=` 되감기 링크가 깨지지 않게).

## 2. 이번 시즌 — 시기별로 바뀌는 화면

| 시기 | 맨 위 | 본문 (왼쪽 넓은 열) | 오른쪽 열 |
|---|---|---|---|
| 정규시즌 | 오늘 경기 매치업 카드 (확률·선발·팀 비교) | 승률을 가른 요인, 오늘 선발 유형, 선발을 바꾸면?, 선수 유형 지도 | **순위표**(오늘 경기 전 기준, 5위 선), **다가오는 경기**(7일), 가을야구 진출 확률, 모델 적중률, 최근 예측 |
| 가을야구 | 오늘 경기 + 맨 위 띠에 시리즈 전적 | 같음 | **가을야구 대진**(시리즈별 전적·경기 결과 — `postseason.json`), 시리즈 전망, 다가오는 경기 |
| 비시즌 (지금) | **시즌 종료 카드**: 우승 팀 + "지난 시즌에서 2026 다시 보기" | 다음 시즌 안내 | — |
| 시범경기 | 오늘 경기 (시범경기 표시) | 같음 | 개막까지 일정 |

샘플에서 만든 것: 메뉴 순서, 시즌 종료 카드, 순위표·다가오는 경기 카드(되감기 날짜를 "오늘"로 보면 정규시즌 화면을 미리 볼 수 있다).

## 3. 지난 시즌 — 연도별 기록실

위에서 아래로:
1. **연도 칩** 2026 → 2015 (연도 + 그해 우승 팀 로고·이름). `?season=`으로 바로 열기.
2. **우승 배너**: 우승 팀 색 면, 로고, "○○에 4승 1패. 11월 8일 대구 5차전 KT 1 : 12 삼성으로 확정."
3. **한국시리즈 경기별 결과**(왼쪽): 차전·날짜·구장·점수·이긴 팀. 2026은 경기 전에 공개한 예측과 적중도 함께. 우천 취소 표시.
4. **우승까지의 길**(오른쪽): 순위 결정전(2021) → 와일드카드(4위 1승 안고 시작) → 준플레이오프 → 플레이오프 → 한국시리즈, 시리즈 전적과 경기별 승리 팀 점.
5. **이 시즌, 모델은 얼마나 맞혔나**: 여러 시즌 시험의 그 시즌 적중률(그 시즌보다 앞선 시즌으로만 학습)과 단순 규칙. 2015~2017은 시험 안 함. 2026은 "경기일 다시 보기" 버튼.
6. **정규시즌 최종 순위**: 순위·팀·승·패·무·승률·게임차·득실차·가을야구 결과(우승/준우승/○○ 탈락).

데이터 2015~2026 12시즌 모두 저장된 경기 기록에서 만든다(우승 팀 12개 모두 실제와 일치 확인).

## 4. 데이터

| 파일 | 만드는 곳 | 내용 | 갱신 |
|---|---|---|---|
| `seasons/index.json` | `kbo_predict.season_archive` | 시즌 목록, 우승·준우승, 한국시리즈 전적 | 시즌이 끝날 때 |
| `seasons/{season}.json` | 같음 | 최종 순위, 가을야구 시리즈·경기, 우승 팀, 그 시즌 모델 성적 | 시즌이 끝날 때 (진행 중 시즌은 매일) |
| `seasons/schedule_{season}.json` | 같음 | 그 시즌 모든 경기(일정·결과, 약 60 KB) — 순위표·다가오는 경기를 브라우저가 계산 | 매일 |
| `postseason.json` | `run_pipeline` (`simulate.postseason_summary`) | 진행 중 가을야구 대진과 경기별 공개 예측 | 매일 (가을야구 중) |

## 5. 적용 순서 (제안)

1. **메뉴·지난 시즌·이번 시즌 순위/일정/시즌 종료 카드** — 샘플을 다듬어 테스트·데이터 계약과 함께 적용.
2. **경기일 다시 보기를 지난 시즌으로 옮기기** — 지금은 이번 시즌 페이지 안에 있다. 지난 시즌 2026 아래에 날짜 슬라이더를 두고, 이번 시즌 페이지는 오늘만 다룬다.
3. **소식 실제 기사** — 네이버 API 키·Cloudflare 가입 후 프록시 배포.
4. (선택) **2018~2025 경기일 다시 보기** — 여러 시즌 시험의 경기별 예측(그 시즌보다 앞선 시즌으로만 학습)을 공개해 과거 시즌도 날짜별로 다시 보게 한다.
